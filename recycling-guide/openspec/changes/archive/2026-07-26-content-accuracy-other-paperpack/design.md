# 설계 · 결정 · 근거

## 검증한 사실 (출처)

### 일반팩 vs 멸균팩
- 일반팩(살균팩): 내부가 흰 종이. 냉장 우유·주스 등. 알루미늄 없음.
- 멸균팩(테트라팩): 내부에 알루미늄 은박. 상온 두유·주스·소주 등.
- 배출: 종이팩 전용수거함에 배출하되 일반팩·멸균팩을 서로 구분. 다른 종이류와 섞지 말 것. 전용함 없으면 종이류와 구분되게 묶어 배출.
- 출처: 세종시 자원재활용, 인천 부평구청, 국민일보 보도(우유팩·멸균팩 종이팩 통합수거), 정관타임스.

### 햇반·즉석밥 용기
- 재질: 폴리프로필렌(PP) 약 95% + EVOH 필름 약 5% 복합. PP 두 겹 사이 필름을 끼운 구조.
- 표시: 용기 바닥에 숫자 없이 `OTHER`. 복합재질.
- 배출: 지자체 분리배출 기준으로는 종량제봉투(복합재질, 선별 불가). '그냥 플라스틱'으로 내면 선별장에서 일반쓰레기로 재분류됨.
- 대안: 제조사(CJ제일제당) 자체 회수 캠페인.
- 출처: 데일리팝, CJ뉴스룸, 한국일보, 블리스고 등.

## 결정

- **모호어 제거.** "재활용 가능" 대신 "전용 회수처가 없으면 종량제"처럼 결과가 갈리는 조건을 명시. 핵심 목표(명확성)에 직접 대응.
- **숫자 없는 OTHER 명시.** 마크 카드 bin 문구를 "대부분 종량제" → "전용 수거처 없으면 종량제(일반쓰레기)"로, tip에 "숫자(7) 없이 OTHER 글자만 있어도 동일" + 햇반 예시 추가.
- **상세가이드 라우팅 확장.** 상세가이드 분기 조건에 `햇반`·`즉석밥` 포함 → OTHER 전용 안내가 뜨도록. (품목명에 'OTHER'가 없어 기존엔 기본 4원칙으로 빠지던 문제 수정.)
- **검색 신규 항목.** `햇반 용기` 항목을 별명(햇반/즉석밥/오뚜기밥 용기/컵밥 용기 등)과 함께 추가해 검색 유입 커버.

## 리스크

- 지자체별로 종이팩 전용함 유무·멸균팩 취급이 다름 → 안내에 "전용함이 없으면" 분기와 거주지 확인 문구 유지.
- 멸균팩을 알루미늄캔류로 오인 배출할 위험 → "종이팩"임을 명시하고 은박은 재질 구분 힌트로만 설명.
