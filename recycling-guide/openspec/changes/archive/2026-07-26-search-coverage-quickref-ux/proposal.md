# 검색 커버리지 확대 + '헷갈리는 정보 빠른 탐색' UX 개선

## 왜
핵심 목표는 "생활 속 자주 헷갈리는 분리배출을 쉽게 찾게" 하는 것. 커버리지 진단 결과, 자주 검색되는 품목이 검색되지 않거나(계란판·유리컵·커피찌꺼기·기저귀 등) 별명 부족으로 안 잡히는 경우(사기그릇·우유곽·뽁뽁이·라벨·뚜껑) 다수 발견. 빠른참조 FAB는 존재감·목적 전달이 약하고, 인기 품목이 상단에 없으며, 카테고리 필터가 정확일치라 일부 품목이 필터에서 누락.

## 무엇을
- 신규 품목 22종 추가(공식자료 검증): 계란판, 계란 껍질, 나무젓가락, 종이 빨대, 커피 캡슐, 텀블러, 보온병, 유리컵, 안경, 볼펜, 신용카드, 화분, 프라이팬, 도마, 종이봉투, 커피 찌꺼기, 기저귀, 생리대, 고양이 모래, 담배꽁초, 일회용 컵, 음식물쓰레기 구분.
- 기존 품목 별명 보강: 사기그릇, 우유곽/우유갑, 뽁뽁이/에어캡/라벨/과자봉지/라면봉지/양파망, 젤·물 아이스팩, 페트병 뚜껑/캡, 스티커, 커피찌꺼기(붙임), 과일/채소/김치(→음식물 구분).
- 빠른참조 UX: FAB 문구 "이건 어디에 버려요?"+시선유도 pulse, 팝업 안내문구, 인기·혼동순 정렬(햇반·컵라면·아이스팩·영수증·종이컵… 상단), 핵심 FAQ 품목 팝업 추가, 카테고리 필터 정확일치→포함 매칭 + 비닐류/대형폐기물 옵션 추가.

## 범위 밖
- 지자체별 실시간 배출요일/전용함 위치 안내(데이터 소스 없음).
- 검토필요 품목(종이빨대·안경·생리대·도마·플라스틱 화분·커피캡슐 일반배출)은 원칙 근거로 추가하되 "지자체 확인" 문구로 헤지, 서울시 품목별 공식 명시 확보 시 갱신.
