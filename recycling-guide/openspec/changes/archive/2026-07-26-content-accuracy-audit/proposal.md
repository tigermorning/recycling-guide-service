# 전 콘텐츠 정확성 감사 — 서울시 최신 기준 대조

## 왜

프로젝트 핵심 목표는 "헷갈리는 분리수거를 명확히". 신규 기능 개발을 멈추고 현재 사이트의 모든 품목·안내 문구를 서울시 최신 공식 기준과 전수 대조해 정확성을 확보한다.

## 검증 원칙

- 공식자료만 근거: ①서울특별시 ②서울시 자치구 ③환경부 ④한국환경공단 ⑤EPR ⑥기타 공공기관. 블로그·카페·유튜브·상업사이트 금지. 상충 시 서울시 우선.
- 추측 금지. 공식 근거 부족 항목은 수정하지 않고 '검토필요'로 분류.
- 모든 수정에 공식 출처 URL + 원문 인용 기록(design.md).

## 범위

- data.json 104개 품목(감사 후 109개), app.js quickRefData 48항목·recycleMarks 16마크·상세가이드, 데이터 오염(한자 혼입) 전수.
- 집중 품목 24종(햇반/컵라면/아이스팩/종이컵/종이팩/영수증/감열지/코팅종이/스티로폼/치약/칫솔/우산/깨진유리/사기/도자기/화장품용기/펌프/캡/라벨/플라스틱빨대/비닐장갑/고무장갑/물티슈/PET병).

## 결과 요약

- 분류/안전 오류 수정 9건, 신규 품목 5건 추가, 데이터 오염 9건 정리.
- 최대 발견: 서울시 2026년 폐비닐 개편(오염돼도 비닐류 배출), 비닐=플라스틱류와 별도 품목.
- 검토필요(공식 근거 부족) 항목은 분류 미변경으로 보존.

## 범위 밖

- 자치구별 실시간 기준 조회(데이터 소스 없음) — 문구로 "거주지 확인" 안내만.
- 지자체 전용수거·기업 회수 캠페인 접수 연동.
